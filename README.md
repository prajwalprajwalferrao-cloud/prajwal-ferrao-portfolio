## ⚡ Getting Started Locally

### Prerequisites
Make sure you have **Node.js** (v18 or higher) and **npm** installed.

### 1. Clone the repository
```bash
git clone https://github.com/prajwalprajwalferrao-cloud/prajwal-ferrao-portfolio.git
cd prajwal-ferrao-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 4. Build for production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.

### 5. Preview production build
```bash
npm run preview
```

## 🌐 Deployment to Vercel

This repository is optimized for one-click deployment on [Vercel](https://vercel.com/):

1. Go to [vercel.com/new](https://vercel.com/new).
2. Select and import `prajwal-ferrao-portfolio`.
3. Vercel automatically detects **Vite** (`npm run build`, output: `dist`).
4. Click **Deploy**.
